# Loan Management System Planning

This repository is being used to plan and build a loan management system inspired by the Service Suite reference application.

## Current status

We are in the discovery and planning stage. The first committed artifact is a structured exploration document for the reference system:

- [`docs/service-suite-discovery.md`](docs/service-suite-discovery.md)

## Intended MVP

The initial product should focus on the core lending workflow:

1. Authentication and role-based access control.
2. Dashboard shell and portfolio metrics.
3. Borrower onboarding and borrower list.
4. Loan product configuration.
5. Loan application and calculator.
6. Approval workflow.
7. Disbursement.
8. Repayment schedules and payment recording.
9. Collections, arrears, and risk reporting.
10. Basic users, roles, settings, and audit logs.

## Next step

After reviewing the discovery notes, the next recommended task is to scaffold the application and create the first static dashboard screen.
